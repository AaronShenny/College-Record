---
name: Desktop UI priorities
description: User's priorities for simplifying the record-making interface.
---

Prioritize fewer clicks, easily findable actions, and less unwanted information
in the desktop application.

**Why:** The user described the UI as “so packed with unwanted information” and
said work should take fewer clicks and be easy to find.

**How to apply:** Evaluate changes against routine record-making tasks, not
only visual appearance. Distinguish setup from daily editing and keep primary
actions clear without removing supported functionality or important errors.
Apply this priority to Settings and sync screens as well, not just the editor.
